# Attendance Management System

A full-stack enterprise attendance management system built with Spring Boot and React.

## 🚀 Technologies

### Backend
- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- Maven

### Frontend
- React
- Vite
- JavaScript
- Recharts

## ✨ Features

- Employee management
- Attendance tracking
- Shift scheduling
- Leave management
- Mission requests
- Attendance reports
- Excel export
- Role-based access control
- Dashboard analytics
- Persian calendar support
- AI-based attendance analysis

## 🏗 Project Structure

attendance-management-system

├── src
│   └── Spring Boot Backend
│
├── frontend
│   └── React Application
│
├── pom.xml
└── mvnw

## ⚙️ Backend Run

./mvnw spring-boot:run

## ⚙️ Frontend Run

cd frontend

npm install

npm run dev

## 📌 Overview

This project provides a complete attendance and human resource management solution with employee portals, management dashboards, reporting tools, and intelligent analysis capabilities.

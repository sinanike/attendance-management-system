فونت‌های دارای مجوز خودت را با همین نام‌ها داخل این پوشه قرار بده:

IRANSansXFaNum-Regular.woff2
IRANSansXFaNum-Medium.woff2
IRANSansXFaNum-Bold.woff2

به دلیل مجوز فونت، فایل‌های فونت داخل این ZIP قرار داده نشده‌اند.

بعد از کپی فونت‌ها:
1) frontend/src فعلی پروژه را با frontend/src این ZIP جایگزین کن.
2) npm run dev را Restart کن.
3) طراحی، رنگ‌ها، منوها و داده‌های زنده تغییری نمی‌کنند؛ فقط فونت فارسی و اعداد عوض می‌شوند.
